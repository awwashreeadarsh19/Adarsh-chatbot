# Adarsh Chatbot

A local health-question chatbot built with [Gradio](https://www.gradio.app/),
[Hugging Face Transformers](https://huggingface.co/docs/transformers/), and the
bundled `phi1.5` language model.

## Features

- Runs locally through a simple browser interface.
- Loads the model and tokenizer from the included `phi1.5/` directory.
- Generates responses to natural-language questions with sampling enabled.

## Project Structure

```text
Adarsh-chatbot/
├── gradio_app.py       # Gradio interface and response generation
├── phi1.5/             # Local model, tokenizer, and configuration files
└── README.md
```

## Requirements

- Python 3.9 or newer
- PyTorch
- Transformers
- Gradio
- Approximately 3 GB of available memory for the local model

## Installation

Create and activate a virtual environment, then install the dependencies:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
pip install torch transformers gradio
```

macOS or Linux:

```bash
source .venv/bin/activate
pip install torch transformers gradio
```

## Running the App

From the project directory, run:

```bash
python gradio_app.py
```

Open the local URL printed by Gradio, usually `http://127.0.0.1:7860`.

### Windows and Linux device configuration

The current script moves the model to Apple Metal (`mps`). Before running on
Windows or Linux, edit the final model-loading line in `gradio_app.py` and
remove `.to("mps")`:

```python
llm_model = AutoModelForCausalLM.from_pretrained(
	"phi1.5", trust_remote_code=True
)
```

This runs the model on the CPU. A CUDA-enabled setup can instead move the model
to an available NVIDIA GPU with `.to("cuda")`.

## Usage

1. Start the app with `python gradio_app.py`.
2. Enter a question in the text box.
3. Submit the question and read the generated response.

The model is loaded locally, so the first launch may take a little time.

## Important Limitations

This is an experimental chatbot and is not a medical professional or a medical
diagnosis tool. Do not use its responses as a substitute for qualified medical
advice. For urgent symptoms or emergencies, contact local emergency services.

Responses are generated by a language model and may be inaccurate, incomplete,
or inconsistent. Do not enter private or sensitive personal information.
